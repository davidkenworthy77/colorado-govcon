30  data-steps  ·  data-step  ·  data-step-dim
How builds work

RIGHT consumes a build beat before it changes slide. LEFT unwinds it. DOWN and UP skip the build entirely — the escape hatch when a question drags you somewhere else.

data-step-dim greys a beat back once the next one lands, so the current point always reads as current. In print, every step is fully built.
